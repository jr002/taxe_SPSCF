# Source frontend

Point d'entrée de l'interface React.

- [`main.jsx`](main.jsx) : montage de l'application.
- [`App.jsx`](App.jsx) : routage et structure générale.
- [`components/`](components/) : composants réutilisables.
- [`pages/`](pages/) : écrans accessibles par route.
- [`api/`](api/) : communication avec l'API backend.
- [`hooks/`](hooks/) : hooks React partagés.
- [`utils/`](utils/) : formatage et calculs frontend.

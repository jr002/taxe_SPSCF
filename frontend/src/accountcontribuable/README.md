# Espace contribuable (`/src/accountcontribuable`)

Dossier réservé à l'espace du contribuable connecté : il accueillera les écrans
qui présentent les **informations d'un contribuable précis** — sa fiche, ses
déclarations, son état fiscal, ses relances et ses droits de communication —
vus par ce contribuable lui-même.

Il est volontairement vide : aucun composant, aucune route et aucun export ne
s'y trouve encore. Les dossiers contribuables consultés par les agents restent
dans [`../frontofficeagent/contribuables/`](../frontofficeagent/contribuables/),
et le backoffice administrateur dans [`../backofficeadmin/`](../backofficeadmin/).
